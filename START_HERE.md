## 🚀 Cómo Empezar (3 Pasos)

### Paso 1: Instalar Dependencias
```bash

```

### Paso 2: Iniciar Servidor
```bash
uvicorn main:app --reload
```

### Paso 3: Cargar Datos y Acceder
```bash
# En otra terminal
python initialize_training_data.py

http://127.0.0.1:8000
```
